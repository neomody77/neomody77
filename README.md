# neomody77

**从应用到系统，把想法做成能运行、能验证的东西。**

我做应用和后端，也折腾 Linux、Android、硬件和本地 AI。
喜欢沿着一个具体问题往下追：从界面、API 和数据库，一直到网络、系统与设备。

### 关注的方向

- **应用与工具** — Flutter、后端服务、CLI，以及减少重复劳动的自动化。
- **AI 与开发工作流** — 本地模型、编码 Agent、可复用的 Skills 和运行环境。
- **系统与硬件** — Homelab、容器、性能分析、Android 移植与设备调试。

### 做事方式

- 先看代码、日志和实际运行结果，再下结论。
- 改动尽量小，保留恢复路径，让实验可以复现。
- 区分「编译通过」「启动成功」和「实际可用」。

<sub>Build it. Measure it. Understand it.</sub>
